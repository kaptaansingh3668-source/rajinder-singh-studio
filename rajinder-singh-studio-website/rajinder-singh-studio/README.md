# Rajinder Singh Studio — Website starter

A responsive, luxury editorial-style static website for an architecture and interior design business targeting London.

## Files
- `index.html` — main website
- `styles.css` — responsive styling and design system
- `script.js` — mobile navigation, header behaviour and enquiry form handler
- `privacy.html` — privacy notice starter (must be reviewed and customised)

## Run locally
Open `index.html` in a browser, or use VS Code Live Server for a local preview.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL to appear in the Pages settings.

For a custom domain, buy a domain from a registrar and follow the DNS instructions shown in GitHub Pages. Never add DNS records by guessing.

## Connect the enquiry form (required before launch)
The form currently does **not** send messages. It validates fields and explains that a form endpoint is required.
1. Create a form with a service such as Formspree.
2. Copy your form endpoint from its dashboard.
3. Open `script.js` and replace the empty `FORMSPREE_ENDPOINT` value with your real endpoint.
4. Test a submission and verify that it reaches the correct inbox.
5. Review provider terms and privacy settings before collecting real enquiries.

Do not put passwords, API secrets or private credentials in this repository.

## Before launch
- Replace concept imagery with your own project images or licensed imagery.
- Keep concept work clearly labelled; do not imply illustrative images are completed client projects.
- Add a real business email and any public business details you want to disclose.
- Review and complete `privacy.html`; this is only a starter template.
- Verify your qualifications and service scope. Do not use protected professional titles or imply regulated services you are not qualified/authorised to provide.
- Check mobile layouts, all links, image loading and form delivery.
- External imagery currently uses Unsplash image URLs and Google Fonts, so internet access is required for those assets.
